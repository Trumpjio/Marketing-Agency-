== Description ==

OrcaPulse is a premium, specialist agency theme designed for growth marketing agencies,
B2B service businesses, and consultancies with global ambition and local-SEO depth.

Features:
* Full design system — colours, typography, components (chips, cards, FAQ, flowchart, timeline).
* Elementor + Elementor Pro compatible (register_elementor_locations supported).
* Ten nav menu locations (Services, Industries, Locations GCC + Global, Studio, Footer x4, Primary).
* Four footer widget areas.
* Mobile-first navigation — logo + hamburger with grouped mobile panel.
* Sticky header with scroll shrink.
* OpenGraph + Twitter card meta auto-generated per page.
* Clean head output (removes WP generator, wlwmanifest, shortlink).

== Installation ==

1. Upload the `orcapulse` folder to `/wp-content/themes/`.
2. Install and activate the recommended plugins (see INSTALL.md).
3. Activate the theme in Appearance > Themes.
4. Build out your menu structure in Appearance > Menus.
5. Build pages with Elementor using the included CSS classes.
